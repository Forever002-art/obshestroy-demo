# 🏗 Telegram-бот «Каталог строительных компаний»

Личная некоммерческая демоверсия каталога строительных компаний и поставщиков. В Telegram можно выбрать город, найти компанию или отправить заявку на размещение. Оплата в демоверсии отключена.

Исходный проект — [Harizmatlk/obshestroy](https://github.com/Harizmatlk/obshestroy).

**Стек:** Python 3.12+, aiogram 3.x, SQLAlchemy 2.x (async), Alembic, SQLite (→ PostgreSQL сменой одной строки),
APScheduler, python-dotenv, openpyxl (экспорт Excel).

## Возможности
- **Пользователь:** каталог по категориям (+ подкатегории «Строительных материалов»), VIP-раздел, поиск
  (название, услуги, материалы, категория, описание, город, регион), карточки, избранное, отзывы 1–5 (один на компанию), контакты.
- **Компания:** пошаговая регистрация (FSM), личный кабинет (редактирование всех полей, фото/логотип, статистика, подписка, отзывы).
- **Администратор (`/admin`):** модерация заявок, управление компаниями и пользователями, блокировка/скрытие/удаление,
  продление подписок, доход, статистика, удаление отзывов, рассылки, экспорт в Excel, бэкап/восстановление БД, редактируемые тексты.
- **Демодоступ:** пробный период после одобрения заявки, ручное продление через админ-панель.
- **Расписание:** при локальном запуске подписки проверяются каждые 30 минут, а резервная копия SQLite создаётся ночью. На Vercel подписки проверяются раз в сутки.

## Новое в версии 1.1
- **Город:** при `/start` бот спрашивает город; каталог, VIP и поиск показывают компании этого города
  (сменить: «Главная → 📍 Город»; «Любой город» отключает фильтр).
- **Умный поиск:** запрос «штукатурка» подскажет раздел «Отделочные работы» и найдёт компании этого раздела
  (словарь — `utils/keywords.py`). В каталоге есть кнопка «Найти по виду работ».
- **Автозаполнение из реестра (ЕГРЮЛ/ЕГРИП) через DaData:** владелец вводит название и город, бот предлагает варианты
  и подставляет название, адрес, регион, категорию (по ОКВЭД). Нужен `DADATA_TOKEN`; без него шаг пропускается.
  Реестр не хранит телефон/сайт/график/фото — их владелец вводит сам.
- **Пробный период:** при одобрении заявки компания получает `TRIAL_DAYS` (по умолчанию 60) дней тарифа «Стандарт» бесплатно, один раз.
  Пробные периоды не попадают в «Доход».
- **Скорость:** короткие транзакции БД, увеличенный таймаут блокировок SQLite, поддержка прокси (`PROXY_URL`).
- Миграция `0002` применяется автоматически при запуске (`AUTO_MIGRATE=true`).

## Чистый чат («один экран»)
Бот держит одно рабочее сообщение: кнопки редактируют его, а введённый пользователем текст/фото удаляется,
и сообщение сразу превращается в следующий шаг. Ошибки ввода показываются на 6 секунд и исчезают.
Отдельными сообщениями остаются только документы (Excel, бэкап), счёт на оплату, альбомы фото и уведомления.
Реализация — `utils/ui.py` (`render`, `toast`).

## Установка
```bash
python3.12 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env               # Windows: copy .env.example .env
```

## Настройка (`.env`)
| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | токен от @BotFather (обязательно) |
| `ADMIN_IDS` | Telegram ID администраторов через запятую |
| `DATABASE_URL` | `sqlite+aiosqlite:///./data/bot.db` или строка подключения PostgreSQL |
| `AUTO_MIGRATE` | `true` — миграции Alembic применяются при старте |
| `DEMO_MODE` | `true` — оплата отключена, обязательно для вебхука |
| `TELEGRAM_WEBHOOK_SECRET`, `CRON_SECRET` | разные секреты для вебхука Telegram и расписания Vercel |
| `SUPPORT_USERNAME`, `TIMEZONE`, `BACKUP_DIR`, `LOG_DIR`, `BACKUPS_KEEP` | прочее |

### Создание администратора
Администратор — это Telegram ID из `ADMIN_IDS` (свой ID можно узнать у @userinfobot). Добавьте ID в `.env`, перезапустите бота
и отправьте ему `/admin` (или нажмите «🛠 Админ-панель» на главной).

### База данных
- По умолчанию SQLite-файл `data/bot.db`; схема создаётся миграциями автоматически (`AUTO_MIGRATE=true`) и категории
  заполняются при первом запуске.
- Команда `python main.py --init-db` применяет миграции и добавляет категории. Она подходит для SQLite и PostgreSQL.
- Встроенные резервные копии и восстановление доступны для SQLite. Для PostgreSQL используйте `pg_dump` и `pg_restore`.
- Новая миграция после изменения моделей: `alembic revision --autogenerate -m "описание"`.

## Запуск
```bash
python main.py
```
Для продакшена — systemd/supervisor/Docker с перезапуском при падении. Логи в `logs/` (`bot.log`, `errors.log`,
`admin.log`, `payments.log`, `registration.log`, `company.log`); действия админов дополнительно пишутся в таблицу `admin_logs`.

## Публикация демоверсии на Vercel

1. Создайте отдельного бота у BotFather и отдельную базу PostgreSQL, например на [Neon Free](https://neon.com/pricing). Используйте прямую строку подключения PostgreSQL с TLS.
2. Скопируйте `.env.example` в `.env`. Укажите `BOT_TOKEN` тестового бота, `DATABASE_URL`, свой Telegram ID в `ADMIN_IDS` и `DEMO_MODE=true`. Для `TELEGRAM_WEBHOOK_SECRET` и `CRON_SECRET` сгенерируйте два разных значения, запустив команду дважды.

   ```bash
   python -c "import secrets; print(secrets.token_urlsafe(32))"
   ```

3. Установите зависимости и подготовьте базу командой `python main.py --init-db`. Повторяйте эту команду при обновлении миграций. Новый каталог создаётся пустым.
4. Импортируйте репозиторий в Vercel как FastAPI-проект. Добавьте в переменные окружения те же `BOT_TOKEN`, `DATABASE_URL`, `ADMIN_IDS`, `DEMO_MODE`, `TELEGRAM_WEBHOOK_SECRET` и `CRON_SECRET`. Файл `.env` храните локально.
5. После появления публичного HTTPS-адреса зарегистрируйте вебхук. Замените адрес и имя бота в примере своими.

   ```bash
   python -m scripts.register_webhook https://your-demo.vercel.app --bot @your_demo_bot
   ```

6. Отправьте тестовому боту `/start`, выберите город и откройте каталог. Для того же токена используйте только один режим получения обновлений.

Состояние диалогов и каталог хранятся в PostgreSQL. Vercel вызывает проверку подписок раз в сутки в интервале 00:00–00:59 UTC. Сообщения об ошибке ввода удаляются при следующем переходе в диалоге.

## Структура
```
main.py  config.py  database.py  scheduler.py
handlers/      user.py, company.py, admin.py
services/      company, payment, statistics, notification, backup, export
repositories/  доступ к данным (SQLAlchemy)
models/        ORM-модели (Users, Companies, Categories, SubCategories, Reviews, Favorites,
               Subscriptions, Payments, Statistics, Notifications, AdminLogs, Settings)
states/ middlewares/ filters/ keyboards/ utils/
migrations/    миграции Alembic
app.py         HTTP-приложение для Vercel
webhook.py     обработка обновлений Telegram и запуск ежедневной задачи
```

## Заметки
- При локальном запуске через `python main.py` незавершённые диалоги сбрасываются после перезапуска.
- Поиск использует нормализованное поле `search_text` (регистронезависимо для кириллицы и в SQLite, и в PostgreSQL)
  и простое отсечение окончаний («лестница» найдёт «лестницы»).
- Лимит фото: Стандарт — 3, Премиум — 8, VIP — 15.
